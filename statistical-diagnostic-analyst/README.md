# Statistical Diagnostic Analyst

A reusable research-analysis skill for diagnosing survey measurement quality, regression assumptions, influential observations, mediation/moderation models, cross-group comparability, and robustness.

## Contents
- `SKILL.md`: execution instructions and analysis workflow.
- `references/`: detailed methodological guidance and decision rules.
- `examples/`: applied examples from a virtual-idol tourism research project.

## Core philosophy
The skill prioritises defensible research decisions over mechanical threshold checking. Case-specific numerical results are illustrations, not universal defaults.
