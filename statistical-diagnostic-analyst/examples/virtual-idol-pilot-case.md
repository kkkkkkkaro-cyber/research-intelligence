# Case: Virtual-idol tourism-intention pilot (N=50)

## Context
China-only pilot. Constructs: fandom participation (FP), perceived immersion (IM), cognitive destination image (CDI), affective destination image (ADI), and tourism intention (IT).

## Reported findings
- Alpha: FP .590; IM .739; CDI .764; ADI .717; IT .624.
- Notable item flags: FP2 item-rest .082 (alpha-if-deleted .651); CDI4 .218 (.796); TI2 .249 (.730); FP4 .238 (.599); ADI1 .296 (.728).
- Construct correlations were positive; IM–ADI was .817 and ADI–IT .765.
- Regression predicting IT: R² .606; only ADI was statistically significant (B .792, p < .001) when FP, IM, CDI, and ADI were entered together.
- VIF ranged from 2.83 to 3.85.
- Alternative IT score TI1+TI3 had alpha .730, but represented a different outcome definition.
- Four relatively influential observations were retained; excluding them changed the IM result.

## Correct interpretation
This pilot identifies measurement and model-diagnostic issues for review. It does not establish causal effects or confirm the final theoretical model. High bivariate correlations alongside non-significant conditional regression coefficients can arise from shared variance among predictors; do not interpret the regression coefficients as simple bivariate relationships.

## Decision principles demonstrated
- Item diagnostics prompt content review, not automatic deletion.
- VIF and discriminant validity are separate.
- Sensitivity analysis describes fragility; it does not select the preferred p-value.
- Valid influential observations remain unless independent exclusion grounds exist.
- Missing Cook's D values and threshold must remain explicitly unavailable.
