# Robustness and sensitivity analysis

## Purpose
Sensitivity analysis tests whether a conclusion depends on defensible analytic choices. It does not identify the model that produces the most favourable result.

## Candidate perturbations
- Alternative but theoretically defensible item composition.
- Pilot wave included versus excluded after questionnaire changes.
- Influential cases retained versus excluded, where exclusion is diagnostically informative.
- Alternative missing-data handling.
- Alternative model specification or estimator.

## Compare
- Sample size and composition.
- Outcome/construct definition.
- Coefficient direction and magnitude.
- Confidence intervals and uncertainty.
- Model fit and explanatory power.
- Whether the substantive interpretation changes.

Do not compare R-squared values as if they rank measurement quality when dependent-variable definitions differ.

## Case illustration
In the pilot, original IT (TI1–TI3) had alpha .624; an exploratory TI1+TI3 score had alpha .730. The models had different outcome definitions, so R-squared .606 versus .552 is not a direct contest. In the main study, analyses were repeated excluding the 50-person Chinese pilot wave (N=250 versus N=300); the report stated that substantive structural conclusions were unchanged. This provides a separate wave-inclusion sensitivity check.
